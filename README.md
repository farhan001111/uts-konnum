Deskripsi
Program ini dibuat untuk menyelesaikan persamaan nonlinier menggunakan metode biseksi. Program dijalankan melalui CLI (Command-Line Interface), sehingga pengguna memasukkan fungsi dan nilai yang diperlukan melalui terminal.

Fitur
- Memasukkan fungsi `f(x)` sendiri.
- Memasukkan batas bawah dan batas atas interval.
- Memasukkan nilai toleransi.
- Menghitung pendekatan akar menggunakan metode biseksi.
- Menampilkan proses iterasi dan hasil perhitungan.


Cara Menjalankan
1. Simpan file program Python, misalnya `main.py`.
2. Buka Terminal atau Command Prompt di folder tempat file disimpan.
3. Jalankan perintah berikut:

   ```bash
   python main.py
   ```

   Jika perintah tersebut tidak bisa digunakan, coba:

   ```bash
   py main.py
   ```

Contoh Input
Misalnya ingin mencari akar dari fungsi `f(x) = x**2 - 4` pada interval 1 sampai 3, masukkan:

- Fungsi: `x**2 - 4`
- Batas bawah: `1`
- Batas atas: `3`
- Toleransi: `0.001`

Akar yang dicari mendekati `x = 2`.
